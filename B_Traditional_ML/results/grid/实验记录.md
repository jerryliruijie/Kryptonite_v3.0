# B 部分：Kryptonite-20 RBF SVM 参数探索

## 实验设置

- 在此前 linear/RBF pilot 的基础上，比较 9 组 RBF SVM：`C` 为 0.1、1、10，`gamma` 为 0.01、0.05、0.1。
- 使用相同的 Kryptonite-20 training 8,400 条和 validation 2,400 条，划分种子 67。每组独立在 training 上拟合 `StandardScaler`；其他 SVC 设置保持一致。
- 分类指标来自 validation 预测；ROC-AUC 使用 `decision_function` 分数。每组均记录完整模型参数、训练耗时和逐样本预测。
- 本次使用同一个 validation 集探索参数；local test 和 hidden 数据未用于评估。调用公共接口时会载入 test 数组，但训练和验证未使用它们。

## Validation accuracy

| C | gamma=0.01 | gamma=0.05 | gamma=0.1 |
|---:|---:|---:|---:|
| 0.1 | 50.83% | 52.42% | 51.75% |
| 1 | 52.38% | 57.17% | 57.38% |
| 10 | 57.00% | 57.63% | **59.00%** |

本次观察到最高 accuracy 的组合是 `C=10, gamma=0.1`。它的 precision 为 **58.77%**、recall **57.98%**、F1 **58.38%**、ROC-AUC **0.6209**；单次拟合耗时 **2.834 秒**，包含标准化和模型拟合。

首轮 RBF `C=1, gamma="scale"` 的 accuracy 为 57.17%；本次最高结果提高 **1.83 个百分点**，对应同一验证集净增加 44 条正确预测。9 组均在同一 validation 集上比较，最高值是本次探索结果；最终模型和未见数据表现仍待后续验证。

各指标应一起看。例如 `C=0.1, gamma=0.1` 的 accuracy 为 51.75%，正类 recall 为 6.22%。全部结果及混淆矩阵见 `grid_results.csv` 和 `grid_results.json`。
