# Sign + CatBoost 学习曲线：开发实验

## 实验设置

- 使用共享 70% training 的 25%、50%、100% 训练 CatBoost，并在相应数据集的共享 20% validation 上评分。K20、K30、K40 的 validation 均已用于 B 的开发；K20 validation 此前还用于 SVM 开发。10% local test 及 hidden 未用于评分。
- 子集仅从共享 training 内按标签分层抽取：先抽 50%，再从该 50% 抽 25%，因此三个规模嵌套。抽样 seed 为 67、123、314，具体原始行索引在 `subsets/`。这些是 **PROPOSED** 小组比较子集，需 A 和小组共同确认或替换。
- 输入为逐特征符号：`x >= 0` 映射到 +1，其余映射到 -1。CatBoost 使用 CPU、depth 10、600 次迭代、learning rate 0.05、L2 10、model seed 67。模型每次从头训练，参数及模型随机种子保持一致。
- 该实验以固定 validation 比较样本规模；此前使用的 3-fold CV 有不同的训练和评估划分，数值应结合各自流程解读。

## 结果

Accuracy 与 sample SD 单位均为百分点。25%、50% 的三个子集相互重叠，共用 validation；SD 用于描述这三个抽样结果的离散程度。100% 的三个记录使用相同训练行、相同行顺序和相同 model seed，结果相同，不提供模型随机性或泛化误差估计。

完整 precision、recall、F1、specificity、ROC-AUC 和计时见 `run_metrics.csv` 和 `summary.csv`；逐样本标签、预测、分数、混淆矩阵和原始行号见 `runs/`。训练准确率接近 100%，在这些 validation 结果上观察到训练与评估差距。较多样本时，三个数据集的平均 validation accuracy 均提高；当前结果适合开发比较，最终表现需使用团队固定方案后的评估。
