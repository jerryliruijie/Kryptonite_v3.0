# Kryptonite-3.0 coursework

This repository contains the code and recorded evidence for the team's response to the supplied Kryptonite-3.0 mock paper. The current manuscript is [paper/MML_CW_Paper.pdf](paper/MML_CW_Paper.pdf). See [docs/reproduction.md](docs/reproduction.md) for the exact training and evaluation protocol.

## Code layout

| Directory | Implementation | Executed notebook |
|---|---|---|
| `baseline/` | Majority, linear and quadratic logistic models | [baseline.ipynb](notebooks/baseline.ipynb): Tables 1 and 2 |
| `mlp/` | Width-256 MLP, training, checkpoint evaluation | [mlp.ipynb](notebooks/mlp.ipynb): Figure 1 and Table 2 |
| `catboost/` | Sign transformation, CatBoost training and learning curves | [catboost.ipynb](notebooks/catboost.ipynb): Figure 2 and Table 2 |
| `lora/` | KryptoNet-40, linear probe and LoRA adaptation | [lora.ipynb](notebooks/lora.ipynb): Table 3 |

Shared data and split helpers are `common.py`, `create_splits.py` and `learning_subsets.py`. `paper/run_strict_87ec2ce_local_test.py` coordinates the four methods for a fresh local-test reproduction. The four notebooks are saved with outputs and actually refit their methods before recalculating the reported tables and figures. Fresh rerun artifacts are in `results/notebook_reruns/`. The two paper figures are generated by `paper/render_mlp_architecture.py` and `paper/plot_paper_learning_curve.py`.

The fixed stratified split uses seed 67: 70% train, 20% validation and 10% local test. Majority/logistic and sign-CatBoost fit on the combined 90%. MLP, linear probe and LoRA fit on the 70% training partition and select checkpoints using validation. Training seeds are 42, 123 and 2026. The reported Table 2 and 3 evidence is in `results/strict_87ec2ce_20261118/`; Figure 2 evidence is in `results/learning_curves_20261117/`.

## Run

Create a Python 3.12 environment and install `requirements.txt`. For a complete fresh local-test run, place the course-supplied `Datasets/` and `kryptonet40.pt` at the project root, then run:

```sh
.venv/bin/python paper/run_strict_87ec2ce_local_test.py train --output results/new_local_test
.venv/bin/python paper/run_strict_87ec2ce_local_test.py evaluate --output results/new_local_test
```

For a single method's development experiment, use `python -m baseline.train`, `python -m mlp.train`, `python -m catboost.pipeline` or `python -m lora.train` with the method's CLI arguments. See [the reproduction guide](docs/reproduction.md). The official hidden-label format checker is `check_submission.py`; the prediction arrays are in `hiddenlabels/`. `paper/export_hidden_labels.py` regenerates them from the recorded seed-42 checkpoints.
